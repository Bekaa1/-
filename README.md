## amoCRM webhook scheduler

Сервис получает webhook-и amoCRM, фильтрует сделки, которые перешли в стадии:
- `2-4 банка`
- `6-9 банка`
- `12+ банка`

Далее:
1. Берет из кастомного поля `886012` количество банок.
2. Если значение не из допустимых (`2, 4, 6, 9, 12, 15`) — отправляет уведомление в Telegram со ссылкой на сделку.
3. Если значение не соответствует текущей стадии (например, `4` в стадии `6-9`) — отправляет уведомление в Telegram и задачи не создает.
4. Если значение валидное и соответствует стадии — создает задачи в amoCRM по расписанию.
5. Сохраняет входящие webhooks и созданные задачи в PostgreSQL для дебага.

### Расписание задач

- `2` банки: каждую неделю, 2 месяца (8 задач)
- `4` банки: раз в 2 недели, 4 месяца (8 задач)
- `6` банки: раз в 2 недели, 6 месяцев (12 задач)
- `9` банки: раз в 2 недели, 9 месяцев (18 задач)
- `12` банки: раз в 2 недели, 12 месяцев (24 задач)
- `15` банки: раз в 2 недели, 15 месяцев (30 задач)

Тексты задач:
- `Прошла одна неделя, нужно позвонить`
- `Прошло две недели, нужно позвонить`

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

`POST /webhooks/amo`
